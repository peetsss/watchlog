# UI brand assets

These SVGs are the `logo/` brand assets recoloured for the dark app:

- transparent background
- mascot `#e7b45a` (app amber)
- lettering and eyes `#f4efe6` (app cream)

The favicon is a transparent head crop just below the eyes. The hands are masked out, the full head width is kept, and the square has breathing room for the browser tab.

Source files live in the repository root under `logo/`.

`tmdb-logo.svg` is the official TMDB attribution asset from
<https://www.themoviedb.org/about/logos-attribution>. Keep it unmodified and
smaller than the watchlog wordmark.
